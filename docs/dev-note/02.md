Đúng hướng. Bạn đang chia thành các tầng: dữ liệu → luật → điều phối → giao diện.

Luồng tổng thể
Caro.jsx (front)
  │  room.play(i)            ← gửi thao tác
  ▼
Room (điều phối, giữ state duy nhất)
  │  isValidMove, calculateWinner
  ▼
rules.js (luật, hàm thuần)     models.js (obj bàn cờ, obj quân cờ)
  │
  └─ Room tạo state mới → báo cho front → front render lại

Front không giữ trạng thái ván. Nó chỉ hỏi room để lấy state, và được room báo khi state đổi.

2. Luật chơi

rules.js:

js
const LINES = [
  [0, 1, 2], [3, 4, 5], [6, 7, 8],
  [0, 3, 6], [1, 4, 7], [2, 5, 8],
  [0, 4, 8], [2, 4, 6],
]

// Hàm thuần: không sửa board, chỉ trả kết quả
export function isValidMove(board, index) {
  return board[index] === null
}

export function calculateWinner(board) {
  for (const [a, b, c] of LINES) {
    const owner = board[a]?.owner
    if (owner && owner === board[b]?.owner && owner === board[c]?.owner) {
      return owner
    }
  }
  return null
}
3. Room: nơi giữ ván đấu

Room.js:

js
import { createBoard, createPiece } from './models.js'
import { isValidMove, calculateWinner } from './rules.js'

export class Room {
  listeners = new Set()
  state = null

  constructor() {
    this.start()
  }

  // Bắt đầu ván mới: khởi tạo bàn cờ và trạng thái
  start = () => {
    this.state = { board: createBoard(), turn: 'X', winner: null }
    this.notify()
  }

  // Front gọi hàm này khi người chơi bấm ô
  play = (index) => {
    const { board, turn, winner } = this.state
    if (winner || !isValidMove(board, index)) return

    // Tạo bàn cờ mới thay vì sửa bàn cũ
    const nextBoard = board.map((cell, i) =>
      i === index ? createPiece(turn) : cell
    )

    this.state = {
      board: nextBoard,
      turn: turn === 'X' ? 'O' : 'X',
      winner: calculateWinner(nextBoard),
    }
    this.notify()
  }

  // Front dùng để đọc state hiện tại
  getState = () => this.state

  // Front đăng ký để được báo khi state đổi
  subscribe = (listener) => {
    this.listeners.add(listener)
    return () => this.listeners.delete(listener)
  }

  notify() {
    this.listeners.forEach((listener) => listener())
  }
}

Có ba điểm cần để ý:

state chỉ nằm ở một chỗ, là room.state. Không có bản sao nào trong React.
Mỗi lần đổi, room tạo object state mới và không sửa object cũ. React nhận biết thay đổi bằng cách so sánh tham chiếu, nên cách này giúp giao diện cập nhật đúng.
Các hàm dùng => để this không bị mất khi React gọi chúng từ bên ngoài, ví dụ onClick={room.start}.
4. Front: chỉ hỏi room và vẽ

Caro.jsx:

jsx
import { useState, useSyncExternalStore } from 'react'
import { Room } from './Room.js'

export default function Caro() {
  // Tạo room một lần khi component xuất hiện
  const [room] = useState(() => new Room())

  // Đọc state từ room, tự render lại khi room báo thay đổi
  const { board, turn, winner } = useSyncExternalStore(
    room.subscribe,
    room.getState
  )

  return (
    <div>
      <button onClick={room.start}>Ván mới</button>

      <div className="board">
        {board.map((cell, i) => (
          <button key={i} className="cell" onClick={() => room.play(i)}>
            {cell?.owner}
          </button>
        ))}
      </div>

      <p>{winner ? `Người thắng: ${winner}` : `Lượt: ${turn}`}</p>
    </div>
  )
}

Front không tự kiểm tra ô trống hay người thắng. Nó chỉ gọi room.play(i) và hiển thị kết quả.

Đây là lợi ích lớn nhất của việc tách core: bạn kiểm tra luật mà không cần mở trình duyệt.

Áp dụng cho cờ vua
Obj quân cờ: { type: 'K', color: 'w', row, col, hasMoved }.
Obj bàn cờ: lưới 8x8 hoặc danh sách quân cờ.
rules.js: isLegalMove(board, from, to) cho từng loại quân, và kiểm tra chiếu.
Room: thêm history để undo, và status như đang chơi, bị chiếu, hết cờ.
Front: chọn quân và hover ô hợp lệ (đây là state UI), rồi gọi room.move(from, to).

Sau này nếu làm chơi online, Room có thể chuyển sang server, còn front vẫn giữ nguyên cách gọi play và đăng ký subscribe.

Bước tiếp theo: tạo các file trên, chạy test.js cho đến khi winner là 'X', rồi mới mở trình duyệt để xem Caro.jsx.
