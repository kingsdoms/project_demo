ChessArena bundles Stockfish.js 19.0.1 Lite, single-thread WebAssembly.

Upstream: https://github.com/nmrugg/stockfish.js
Release: https://github.com/nmrugg/stockfish.js/releases/tag/v19.0.1
Source tag commit: 0d5dd7944f88c817c07a26bc4fb1905d5f9c46d6

The unmodified release files stockfish-19-lite-single.js and
stockfish-19-lite-single.wasm are served as stockfish.js and stockfish.wasm.
Only filenames were changed, so the loader resolves its sibling WASM locally.

The application adapter is in src/games/chess/bot/stockfish/.
The local rules engine validates every UCI move before it is applied.
Difficulty labels are resource/skill presets, not calibrated Elo ratings.

Rebuild input supplied beside the archive:
nn-61e7af4bb97d.nnue (1,166,381 bytes)
SHA256: 61e7af4bb97d51eeeb25d322916f86513b5cd3a827ce189c98c6e31946f99e5b
Origin: https://tests.stockfishchess.org/api/nn/nn-61e7af4bb97d.nnue

To rebuild the Lite single-thread engine, extract source-v19.0.1.zip, copy
nn-61e7af4bb97d.nnue into the extracted src/ directory, install/activate
Emscripten 6.0.9 and the upstream Node/make prerequisites, then run from that
source tree:
    node build.js --lite --single-threaded --no-split
See the source archive README and build.js for the original build process.
