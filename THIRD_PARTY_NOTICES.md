# Third-party components

## Stockfish.js 19.0.1 Lite

The application serves the upstream single-thread WebAssembly release locally from public/stockfish/. The original release loader and WASM have only been renamed to stockfish.js and stockfish.wasm.

- Upstream release: https://github.com/nmrugg/stockfish.js/releases/tag/v19.0.1
- Source commit: 0d5dd7944f88c817c07a26bc4fb1905d5f9c46d6
- License: GNU GPL version 3, public/stockfish/COPYING.txt.
- Authors: public/stockfish/AUTHORS.txt.
- Tagged source: public/stockfish/source-v19.0.1.zip.
- Required Lite network: public/stockfish/nn-61e7af4bb97d.nnue.
- Provenance, checksums and rebuild instructions: public/stockfish/NOTICE.txt.

## Be Vietnam Pro

The Vietnamese font family is served locally with four weights from public/fonts/be-vietnam-pro/. Its SIL Open Font License, metadata, pinned upstream source and checksums are supplied in that directory.
